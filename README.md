# DayWise – Intelligent Daily Planning System

## Overview

DayWise is a personal planning system that transforms daily tasks, routines, and commitments into realistic time-based schedules.

Unlike traditional to-do applications, DayWise aims to help users plan their time, adapt to changes, and compare planned activities with actual progress.

## Features

- Daily task and routine management
- Time-based schedule generation
- Task prioritization and scheduling
- Persistent JSON-based storage
- Planning history and progress tracking

## Technologies

- Python
- Tkinter
- JSON
- Scheduling algorithms

## Project Structure

- `core/` – Core planning and scheduling logic
- `data/` – Project data
- `models/` – Data models
- `storage/` – Data persistence
- `tests/` – Tests
- `ui/` – User interface
- `utils/` – Utility functions
- `main.py` – Application entry point

## How to Run

1. Install Python on your computer.
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Run:

```bash
python main.py
```

## Project Goal

To help users plan realistic days, monitor progress, and improve future schedules based on the difference between planned and completed activities.
